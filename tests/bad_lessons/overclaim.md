# Introduction to RAG

## 1. What is RAG?
RAG stands for Retrieval-Augmented Generation. It connects Large Language Models (LLMs) to external files. An LLM is a machine learning model.

## 2. Why Does RAG Matter?
RAG completely eliminates 100% of AI hallucinations and mistakes. With RAG, the model is guaranteed to never produce false information ever again. It also gives fresh knowledge and accesses private company files.

## 3. How Does RAG Work?
Phase 1 prepares documents by chunking and embedding them into a vector database.
Phase 2 embeds the user prompt, retrieves matching chunks, and generates the answer.

## 4. Worked Step-by-Step Example
User Question: What is the fee?
The system embeds the question into numbers and finds the matching chunk.
Retrieved chunk: Late fee is 50.
Final Answer: The late fee is 50.

## 5. Limitations
RAG can be expensive and slow.
